## Repaired defects

- Restored the pnpm lockfile and explicit workspace package dependencies.
- Removed reliance on global TypeScript installations and Corepack downloads.
- Corrected strict TypeScript, ESLint, exact optional property, and runtime-boundary errors.
- Applied the repository Prettier policy to all maintained source files.
- Fixed CLI bundling for package-private aliases and direct workspace source resolution.
