# Dòng chảy thuật toán

:::objectives

- Mô tả một thuật toán bằng các bước có thứ tự.
- Kiểm chứng thuật toán bằng một chương trình nhỏ.
  :::

Một thuật toán biến dữ liệu đầu vào thành kết quả qua chuỗi thao tác xác định.

| Thành phần | Vai trò               |
| :--------- | :-------------------- |
| Input      | Dữ liệu ban đầu       |
| Process    | Các phép biến đổi     |
| Output     | Kết quả quan sát được |

:::activity id="algorithm-order"
:::

> [!NOTE]
> Thứ tự bước là một phần của tính đúng đắn.

:::activity id="sum-program"
:::

:::summary title="Ghi nhớ"
Thuật toán tốt phải rõ đầu vào, trình tự và đầu ra.
:::
